# Annotation Diagnostics

The existing review material is single-rater (`rater01`) annotation with AI-assisted review. AI-modified records are described as AI-assisted review, not as a second independent annotator. There was no independent double-blind annotation and no inter-rater kappa calculation.

The random set contains 32 CC and 32 MCI image pairs. On CC, RSACA was labeled correct on 21/32 versus CARD 22/32; direction errors were 4/32 versus 2/32, spatial relation errors 3/32 versus 4/32, and key omissions 4/32 versus 5/32. CARD had one overall `U`, so the strict overall paired correctness analysis has 31 evaluable pairs. On MCI, RSACA was correct on 23/32 versus CARD 21/32; direction errors were 7/32 versus 4/32, spatial relation errors 1/32 versus 3/32, and key omissions 1/32 versus 4/32. Error categories overlap and their denominators are category-specific as recorded in the source JSON; language issues are separate from factual errors.

Four targeted examples remain separate from the random sample: CC `val_000125`; MCI `val_000056`, `val_001413`, and `val_000155`. They were selected because of known text differences and cannot estimate overall rates. The last case contains a shared house-count factual error in the AI-assisted record. These historic labels apply only to the historic captions. No labels were copied onto predictions that this experiment did not generate, no validation references were modified, and no new human or AI semantic review was performed.

New CC prediction packets are available at `../runs_card_env/annotation_diagnostics/`. `random_cc_new_predictions.json` maps all 32 random CC aliases to their source image IDs and contains the new C0/N1 captions; `targeted_cc_new_predictions.json` separately contains the four targeted IDs `val_000125`, `val_000056`, `val_001413`, and `val_000155`. The mapping retains alias and source ID only; historic captions, reference text, and labels were not copied onto these predictions. These new captions have not received human review or AI review.

No MCI random-sample packet was generated because the registered stage-C transfer check was not entered after the stage-A gate failed. The historical annotations remain single-rater `rater01` with AI-assisted review, not independent double-blind annotation; no kappa is claimed. Random and targeted examples remain separate, the targeted cases do not estimate overall error rates, and any shared CC/MCI imagery must not be counted as independent observations.

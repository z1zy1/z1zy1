# Implementation and Tests

The isolated worktree reuses the V1 `context_pre_norm` implementation. Its whole-adapter path computes `query + dropout(gamma * LN(semantic_context))` before the shared reliability gate; at gamma zero this is an identity residual. The legacy path computes `LN(query + dropout(gamma * semantic_context))` and then applies the whole-adapter gate. No model parameters or tensor shapes were added.

Changes in the isolated worktree:

- Added the unique `exploratory_norm_context_pre_20261015` protocol identifier and included it in immutable P1-style validation artifact handling without reusing an old protocol ID.
- Added a formal-test phase guard for this protocol.
- Allowed the new ID in the existing five-metric equal-weight-log validation selector; its reference constants, 1,000-step grid, and earlier-step tie break are unchanged.
- Added `run_exploratory_norm_pair.sh`, which fixes the shared configuration, permits only `train` or `select`, enforces 10,000 updates and requires CUDA before training.
- Added a paired initialization-summary comparator for every detector and decoder parameter name, shape, dtype, and SHA-256.
- Added focused tests for protocol registration, formal-test rejection, and exact initialization-summary comparison. Existing V1 tests already cover zero-gamma identity, gradient flow, empty semantic maps, ignore regions, and checkpoint compatibility/save-load behavior.
- After resources were restored, added an amendment-recorded `smoke` action capped at 100 updates with a separate output root; it cannot be used as a formal-run checkpoint.
- Saved the complete source patch at `../CODE_DIFF.patch`; SHA-256 is registered in the protocol.
